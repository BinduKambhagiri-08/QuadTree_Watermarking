Divide & Conquer Base Case

Recursion terminates when current size s == minimum_block_size. The base case computes block variance σ2. If σ2 ≥ T, the block's anchor pixel (x, y) is designated for 1-bit LSB embedding.

Spatial Variance Texture Analysis

Human Visual System (HVS) masking: textured regions exhibit high spatial variance, allowing pixel modifications without perceptible visual artifacts.

HVS Masking Principle

Smooth Regions (Low Variance)

Flat color and subtle gradients have variance σ2 < T. The human eye easily spots 1-bit LSB modifications in smooth surfaces as visible dithering noise. Rejected by QuadTree.

Textured Regions (High Variance)

Edges, fine lines, foliage, and high-frequency patterns have variance σ2 ≥ T. Masked by natural image activity, 1-bit changes are completely invisible to human observers. Selected for Watermarking.

Mathematical Formulations

Mean Squared Error (MSE)

MSE = (1 / (M × N)) ∑i,j [ I(i,j) - Iw(i,j) ]2

Quantifies cumulative Euclidean variance between original canvas I and stego-image I_w.

Peak Signal-to-Noise Ratio (PSNR)

PSNR = 10 × log10( 2552 / MSE )

Logarithmic decibel metric. When MSE → 0, PSNR → ∞ dB (lossless identity).

Recurrence Relation & Master Theorem

Master Theorem Case 1
T(n) = 4T(n / 2) + o(n2)
Where: a = 4 (quadrants), b = 2 (subdivision factor)
Step 1

Compute critical exponent: logb(a) = log2(4) = 2. Thus nlogb(a) = n2.

Step 2

Subdivision step at non-leaf node takes constant coordinate splitting f(n) = O(1) = O(n2 - ε) with ε = 2.

Step 3

By Master Theorem Case 1: T(n) = Θ(nlogb a) = Θ(n2).

Important Clarification

In our implementation, variance is calculated only at leaf blocks. Total leaf pixels sum to N2. For fixed leaf size S, total time is strictly Θ(n2).

DAA Viva Voce Preparation Guide

Essential theoretical concepts, algorithm definitions, and frequently asked viva questions with clear answers for academic project evaluation.

Divide and Conquer breaks a problem into smaller independent subproblems of the same type (Divide), solves them recursively until a trivial base condition is reached (Conquer), and merges their results into the final solution (Combine).

A QuadTree decomposes a 2D spatial region recursively into four non-overlapping quadrants: Top-Left (NW), Top-Right (NE), Bottom-Left (SW), and Bottom-Right (SE). Each quadrant has half the dimension (width/2, height/2) of its parent node.

Recursion terminates when block_size ≤ minimum_leaf_size (configured to 8, 16, or 32 pixels). Instead of dividing further, the algorithm computes the block's spatial variance and classifies it as selected (textured) or rejected (smooth).

Due to the spatial masking properties of the Human Visual System (HVS), humans are highly sensitive to noise in smooth, uniform areas but cannot perceive subtle 1-bit intensity variations within busy, textured patterns and sharp edge boundaries.

In an 8-bit grayscale pixel (0-255), the 0th bit contributes only 20 = 1 to the pixel's luminosity. LSB embedding clears this bit using a bitwise mask (pixel & 0xFE) and inserts a watermark bit via bitwise OR (| bit).

The 64-bit header consists of a 32-bit Magic Identifier (0x5154574D) to verify watermark authenticity and a 32-bit message length integer. This allows blind extraction without hardcoding message lengths or prior knowledge of the text.

For an N × N image with a fixed minimum block size S, the total number of leaf blocks is (N/S)2. Because all leaf blocks partition the image without overlap, the total variance calculation across all leaves scans N2 pixels exactly once. Hence, time complexity is Θ(N2).

Spatial LSB watermarks are fragile against lossy JPEG compression, aggressive spatial cropping, resizing, and Gaussian filtering, as lossy algorithms discard high-frequency least significant bits. In production, frequency-domain methods (DCT/DWT) are preferred for robustness.
